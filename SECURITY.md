# Security Policy

## Supported Versions

Only the latest release on the `main` branch receives security updates.

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub's Security Advisories feature:
[Report a vulnerability](https://github.com/esammostafa9-cloud/floravision-flower-classification/security/advisories/new).
Do not post suspected vulnerabilities in public issues. The project maintainer will review reports
and coordinate fixes through that private channel.
